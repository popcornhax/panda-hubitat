ESPHome firmware for the BIGTREETECH Panda Touch

A Hubitat wall panel that stays on your network.

panda-hubitat turns the Panda Touch into a touch dashboard for Hubitat Elevation. The panel talks directly to Hubitat’s local Maker API over your LAN, with no Home Assistant, MQTT, native ESPHome API, or cloud service.

Get started View source

Features

Touch dashboard

An LVGL interface with up to eight pages plus Settings, 32 selected devices, and six device cards per page.

Lights and sensors

On/off and dimmer control for verified lights. Motion, presence, contact, water, weather, temperature, humidity, illuminance, power, and voltage are read-only.

Browser layout editor

Import devices from Maker API, arrange pages, rename cards, set colors, text size, and a background image. Changes apply after a restart, with no rebuild.

Screen sleep

Optional backlight sleep that wakes on motion, on touch, or from the editor. The panel stays online while the screen is dark.

Weather view

Tap a weather tile for a three-day forecast built from the attributes your Hubitat weather driver reports.

Maintenance

Encrypted ESPHome OTA updates, read-only discovery scripts, and a verified full-flash backup tool to run before replacing the factory firmware.

How it works

  1. Browser on your LANEdits layout on port 80
  2. Panda TouchESPHome, ESP-IDF, LVGL
  3. Hubitat hubBuilt-in Maker API over local HTTP

There is no driver or app to install on the hub. A command counts as done only after a fresh state read shows the requested state, and controls are disabled unless Wi-Fi, the hub, and recent device state are all valid. Locks, doors, garage, alarm, security, valve, gate, barrier, shutter, blind, shade, and access-control devices are excluded from selection and control.

Trusted networks only

The browser editor is intentionally unauthenticated and uses plain HTTP. Do not port-forward it or expose the panel to guest or untrusted networks. Same-origin checks help block cross-site browser requests, but they do not authenticate other software on your LAN.

Hardware

  • BIGTREETECH Panda Touch: ESP32-S3, 16 MB flash, 8 MB octal PSRAM, 800×480 RGB LCD, GT911 touch.
  • The Panda Touch magnetic USB-C dock (CH340K USB-UART) for the first serial install, flash backup, and recovery.
  • A Hubitat Elevation hub that the panel can reach at a private IPv4 address, with the built-in Maker API app.
  • A 2.4 GHz Wi-Fi network.

Pin mappings come from the BTT pinout and are defined in panda-hardware.yaml.

Get started

You need macOS or Linux, uv, and network access. The README setup guide is the full reference.

  1. Clone and bootstrap

    git clone https://github.com/popcornhax/panda-hubitat.git
cd panda-hubitat
./scripts/bootstrap.sh
cp secrets.example.yaml firmware/secrets.yaml

  2. Create a Maker API instance

    In Hubitat, open Apps → Add Built-In App → Maker API. Enable local access only and select only the lights and sensors the panel should use.

  3. Fill in your secrets

    Replace every example value in firmware/secrets.yaml: Wi-Fi, an OTA key from openssl rand -base64 32, and the hub address, numeric app ID, and access token. The file is ignored by Git; keep it private.

  4. Discover and select devices

    Replace 12,27 with IDs you reviewed in your own discovery results.

    .venv/bin/python scripts/hubitat_discover.py
.venv/bin/python scripts/hubitat_discover.py --select 12,27

  5. Validate and build

    These commands compile only. They never flash or upload to a device.

    ./scripts/validate.sh
./scripts/build.sh

  6. Back up, then install over USB

    Make a verified full-flash backup of the factory firmware first by following the recovery guide. Stop if the chip identity, flash size, or security checks do not match. Then replace PORT with your dock’s serial device. 

    .venv/bin/python scripts/generate_dashboard_config.py
.venv/bin/esphome run firmware/panda-touch.yaml --device PORT --upload_speed 115200

Afterwards, open the editor at http://panda-touch.local/. Later firmware updates can use encrypted OTA.

The clock’s time zone is fixed to US Central and temperatures default to Fahrenheit. See Configuration to change either before building.

Project status

Flashed and tested on one Panda Touch. Display, touch, backlight, Wi-Fi, encrypted OTA, Hubitat discovery, light control, the layout editor, and screen capture have been exercised on hardware. Wi-Fi loss and brightness persistence across restarts are still untested, and recovery flashing is documented but has not been tried on hardware. The validation record lists what has and has not been checked.
