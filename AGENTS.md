# Project instructions

This repository contains ESPHome firmware for the BIGTREETECH Panda Touch.
Read [docs/agent-contract.md](docs/agent-contract.md) before changing firmware,
build scripts, or hardware assumptions. Keep credentials out of tracked files.
Do not add Home Assistant API, MQTT, or device controls until the Maker API
discovery and device mapping are documented. Never flash hardware as part of
validation unless the user explicitly requests it.
